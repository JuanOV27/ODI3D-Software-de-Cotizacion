# ODI3D - Software de Cotización

## Descripción

**ODI3D** es un software web desarrollado para la **cotización de proyectos mediante un laminador web**, permitiendo gestionar y procesar la información necesaria para generar una cotización de manera estructurada.

El proyecto busca facilitar el proceso de cotización mediante una aplicación web, integrando la lógica necesaria para recibir, procesar y presentar la información relacionada con los proyectos.
